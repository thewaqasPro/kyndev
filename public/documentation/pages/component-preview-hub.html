Component Isolation Preview & Developer Hub

How to test, preview, and benchmark interactive 3D sections and UI blocks in total isolation using /preview and /hub.

1. The Isolation Previewer (/preview)

Testing WebGL components within a multi-thousand-pixel scrolling page makes isolating physics bugs or shader glitches difficult. To solve this, the repository includes a standalone component preview harness at /preview.

The preview harness renders:

  • Hero Jacks 3D Physics Section: Isolated collision parameters and canvas bindings.
  • Reel Video Showreel: Character rollups and video modal textures in a clean viewport.
  • Featured Cards Gallery: 2.5D tilting card physics.
  • Goal Space Tunnel: Glass voronoi shader and astronaut particles.
  • Individual UI Modules: Header menus, sound toggles, and footer forms.

2. The Developer Navigation Hub (/hub)

The studio navigation hub is accessible at /hub. It acts as an internal sitemap and index of every active route, dynamic case study, and experimental lab section on the site.

Route Path Target Feature Purpose
/preview Component Isolation Harness Previews ready-to-use sections one by one with live controls.
/hub Developer Route Index Full internal map of all 33 generated static pages.
/hero-tools Marketing Tools Hero Isolated 4-corner grid 3D tools section.
/?debug-k K-Morph Live Debugger Floating HUD to freeze and tune letter folding.

3. Adding a New Component to the Previewer

When you create a new section (e.g. src/components/pricing/PricingSection.astro), add it to src/pages/preview.astro:

src/pages/preview.astro 
---
import Layout from '../layouts/Layout.astro';
import PricingSection from '../components/pricing/PricingSection.astro';
---

<Layout title="KYNDEV - Component Preview">
  <div class="preview-stage">
    <div class="preview-item">
      <span class="preview-label">Pricing Section Matrix</span>
      <PricingSection />
    </div>
  </div>
</Layout>

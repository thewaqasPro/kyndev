Multi-Page & SPA Routing Architecture

How Astro static page generation seamlessly coordinates with client-side Single Page Application (SPA) routing, Three.js WebGL persistence, and building 10–20+ routes with zero WebGL boilerplate.

1. The SPA & WebGL Lifecycle Pipeline

KYNDEV operates as a static site generated by Astro, but upon initial page delivery, it runs an in-memory client-side router (RouteManager.js) and lifecycle orchestrator (PageManager.js).

This guarantees:

  • Zero WebGL Context Loss: The Three.js canvas, post-processing FBO pipeline, and WebGL state persist across navigations without reloading or re-allocating textures.
  • Smooth Cinematic Transitions: Navigation between pages triggers the unified K-overlay transition without hard page reloads.
  • Virtual Inertia Scrolling: ScrollManager.js coordinates scroll physics consistently across routes.

2. Adding 10 to 20+ New Routes Effortlessly

Adding new pages in KYNDEV requires no manual Three.js wiring. Any page can be assembled using standard Astro syntax:

Step 1: Create the Astro Page

Create a file in src/pages/case-studies.astro:

src/pages/case-studies.astro 
---
import Layout from '../layouts/Layout.astro';
import Reel from '../components/home/Reel/Reel.astro';
import Goal from '../components/home/Goal/Goal.astro';
---

<Layout
  title="KYNDEV - Case Studies"
  description="Explore our interactive design and engineering case studies."
  ogUrl="https://kyndev.com/case-studies/"
  scrollNavPath="/contact"
  scrollNavText="Get In Touch"
>
  <div id="case-studies" class="page">
    <!-- Any interactive section placed here auto-binds WebGL! -->
    <Reel />
    <Goal />
  </div>
</Layout>

Step 2: Optional Custom Page Class

If your page requires custom color accents or route enter/leave logic, create src/scripts/runtime/navigation/pages/CaseStudiesPage.js:

src/scripts/runtime/navigation/pages/CaseStudiesPage.js 
import Page from './Page.js';
import properties from '../../core/Properties.js';

class CaseStudiesPage extends Page {
  path = "case-studies";
  id = "case-studies";
  endVisualColor = properties.blueColorHex;
}

export const caseStudiesPage = new CaseStudiesPage();
export default caseStudiesPage;

3. Landing Animation Stability Fix

Previously, on initial visit, the page would sometimes flash or restart its fade-in animation at ~1.5 seconds.

The Solution
In PageManager.js, _onHideTextComplete() was updated to verify !this.isFirstRoute before calling _showPage(). Additionally, the 1500ms safety watchdog in TransitionOverlay.js is now only armed during genuine route transitions, completely eliminating duplicate triggers on initial boot.

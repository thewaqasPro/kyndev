Project Architecture & File Structure Breakdown

In-depth technical breakdown of the source files, static routes, modular data layer, runtime deconstruction, and dev server troubleshooting.

1. Key Project Metrics

⚡
Modular Data Layer
All site copy, navigation links, numbers, client logos, awards, and form options decoupled into strictly typed TypeScript files under src/data/.
📄
34 Static Routes
Built in ~1.1 seconds via Astro SSG, including 20 detailed project case studies, 6 specialized service verticals, and 3D prototype stages.
🧩
48 Runtime Modules
Deconstructed from the original 26,946-line monolithic runtime.js into 11 clean, maintainable domains.

3. Type-Safe Content Architecture

Every page section imports its default copy, links, and structured arrays from src/data/. Components accept optional props matching their data structure (via interface Props extends Partial<DataType>) for 100% backward compatibility:

Page Domain Content Files Managed Content
src/data/common/ header.ts, footer.ts, endSection.ts Top navigation menu, CTA action, footer copyright, office locations, inquiry banner.
src/data/pages/home/ hero.ts, heroTools.ts, reel.ts, featured.ts, goal.ts Original 3D Balloons hero, 3D Marketing Tools deck copy/HUD, video modal URL, 12 featured projects, mission narrative.
src/data/pages/about/ who.ts, clients.ts, awards.ts, capability.ts Studio manifesto, team profiles, client logo carousels, 58 awards breakdown, 4 capability pillars.
src/data/pages/services/ hero.ts, capabilitiesShowcase.ts, process.ts, philosophy.ts Services headline, capabilities matrix cards, 4-step delivery pipeline, studio ethos values.
src/data/pages/contact/ hero.ts, form.ts Contact hero prompt, service checklist pills, budget tiers, direct emails, and social links.
src/data/pages/hub/ hero.ts, cards.ts Engineering catalog filter tags, prototype cards, route badges, and technical summaries.

4. Dev Server Commands & Verification

Useful commands for local development and QA validation:

# Typecheck all content files and TypeScript components
npx tsc --noEmit

# Validate smooth SPA transitions and container IDs
npm run check:pages

# Build all static pages for production
npm run build

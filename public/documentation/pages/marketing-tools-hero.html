Marketing Tools Hero 3D Architecture (/hero-tools)

Architecture, grid alignment, official vector brand SVGs, and 3D canvas layering for the Marketing Tools Hero section.

1. Section Overview

Located at /hero-tools (implemented in src/pages/hero-tools.astro), this section presents floating 3D marketing badges (Meta Ads, Google Ads, TikTok, Shopify, Klaviyo, GA4) alongside the agency value proposition.

2. The 4-Corner Grid System

The layout uses a 4-corner CSS Grid layout where textual content and key agency metrics occupy the four perimeter corners, leaving the center area unobstructed for the interactive 3D WebGL canvas:

Corner Position Element / Content Layout Class
Top-Left Main Headline: "MARKETING THAT SCALES REVENUE" .hero-corner-tl
Top-Right Technical Overview & Core Capabilities Subtext .hero-corner-tr
Bottom-Left Primary CTA: "SCALE YOUR CAMPAIGNS" .hero-corner-bl
Bottom-Right Interactive 3D Tool Inspector & Metric Readout .hero-corner-br

3. Z-Index Layering Hierarchy

To ensure HTML text remains sharp, selectable, and crisp above the Three.js canvas: 

/* 1. Base 3D Canvas (Background) */
.hero-canvas-container {
  position: absolute;
  inset: 0;
  z-index: 1; /* Below text overlays */
}

/* 2. Four Corner Text Grid (Foreground) */
.hero-grid-overlay {
  position: relative;
  z-index: 10; /* Crisp interactive typography above 3D */
  pointer-events: none;
}

.hero-grid-overlay a, 
.hero-grid-overlay button {
  pointer-events: auto; /* Re-enable pointer events for CTAs */
}

4. Official Vector Brand SVGs

All 3D tools in the scene use official, high-resolution vector SVGs to avoid artifacting or pixelation:

  • Meta Ads: Official Meta infinity loop gradient vector.
  • Google Ads: Tri-color yellow, blue, and green polygon vector.
  • TikTok Ads: Precision cyan/red chromatic offset music note vector.
  • Shopify Plus: Official Shopify bag vector.
  • Klaviyo: Minimalist chevron flag vector.
  • Google Analytics 4: Orange and yellow bar/pie analytics logo.

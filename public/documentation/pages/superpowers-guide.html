Superpowers for Coding Agents

Overview of the installed Superpowers software development methodology, composable skills library, and Antigravity tool mappings for KYNDEV.

⚡ Installed in KYNDEV
Superpowers is installed locally in this repository under .gemini/skills/ and .agents/skills/, and automatically loaded on agent session startup via GEMINI.md and AGENTS.md.

1. What is Superpowers?

Superpowers is a software development methodology for coding agents. Instead of prematurely writing speculative code, agents follow structured engineering workflows:

  1. Brainstorming & Spec Extraction: Teases out user requirements and clarifies design decisions before touching code.
  2. Architecture Planning: Drafts concise, structured implementation plans with test verification steps.
  3. Disciplined Execution: Emphasizes Test-Driven Development (TDD), YAGNI (You Aren't Gonna Need It), and DRY principles.
  4. Verification Before Completion: Confirms real evidence of success (e.g. clean builds, passing tests) before claiming completion.

2. Installed Skills Catalog

Skill Name Trigger Moment Core Workflow
using-superpowers Session Start Establishes skill enforcement rules and tool platform adaptations.
brainstorming New Features / Ideas Explores alternatives, specifies interfaces, and validates requirements.
writing-plans Multi-step Tasks Produces clear, actionable implementation task lists with test criteria.
executing-plans Plan Execution Coordinates step-by-step implementation, review, and verification.
systematic-debugging Bugs & Broken Builds Root-cause isolation before applying targeted, minimal fixes.
test-driven-development Writing New Logic Red-Green-Refactor testing cycles.
verification-before-completion Finishing Tasks Guarantees commands have run and outputs verified before reporting done.
subagent-driven-development Large Refactors Dispatches focused subagents to work through engineering tasks.
using-git-worktrees Feature Isolation Creates isolated git worktrees without duplicating disk storage.

3. Antigravity Tool Mapping

When Superpowers skills request actions, the Antigravity agent harness maps them to native capabilities:

Action Requested by Skill Antigravity Native Tool
Dispatch Subagent invoke_subagent (using TypeName: "self" for full capability, or "research" for read-only).
Task Tracking / Todos Maintains a task artifact (markdown checklist saved to conversation brain, updated as steps finish).
Code Inspection client_view_file for project workspace files.
File Modifications client_create_file and client_edit_file.
Command Execution run_command (shell commands, npm run build, git commands).

4. Project Configuration & Bootstrap Files

  • GEMINI.md: Bootstraps @./.gemini/skills/using-superpowers/SKILL.md and the Antigravity tool mappings for Gemini / Antigravity harnesses.
  • AGENTS.md: Provides project guidelines and skill references for Cursor, Codex, Devin, and Claude Code.
  • .gemini/skills/ & .agents/skills/: Project-local skill storage ensuring anyone running this repository has access to the full Superpowers skill suite.

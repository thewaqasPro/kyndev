System Architecture Overview

KYNDEV merges static build performance from Astro with an advanced client-side WebGL & physics runtime deconstructed into 11 specialized domains:

Directory Domain Responsibility Key Singletons & Controllers
src/scripts/runtime/core/ Foundation math, viewport uniforms, dynamics, device profiling math, properties, settings, input, ease
src/scripts/runtime/webgl/ Three.js renderer, post-processing stack (SMAA, Bloom, FSR) app, postprocessing, fboHelper, blur
src/scripts/runtime/scenes/ Interactive 3D stages (Balloons, Moon rock, FLIP fluid, Tunnels) homeBalloons, aboutHero, goalTunnels
src/scripts/runtime/navigation/ SPA router, dynamic page controllers, scroll physics routeManager, pagesManager, scrollManager
src/scripts/runtime/ui/ Preloader, route transition canvas, navigation overlays preloader, transitionOverlay, header, links

Trigger Method Target Feature Action

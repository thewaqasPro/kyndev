KYNDEV / Documentation / Hub

KYNDEV Master Developer Portal

The comprehensive architecture and developer hub for the KYNDEV high-performance 3D WebGL and Astro application. Fully self-contained, offline capable, and organized into clear domain guides.

💡 Fast Offline Access & Dev Server Integration
This documentation is 100% self-contained with zero runtime dependencies. You can open any page directly in macOS Finder by double-clicking documentation/index.html, or visit http://localhost:4321/documentation/ whenever your local development server is running.

3. Developer Quick Keys & URL Shortcuts

Shortcut / URL Target Feature What It Does
/projects Projects Portfolio Interactive 2.5D depth cards with raymarching parallax and kinetic tilt.
?debug-k Transition Overlay Injects the floating HUD to freeze, test morph fold, zoom dissolve, and corner radius live.
/preview Component Isolation Opens the standalone stage previewing each 3D component individually.
/hub Developer Hub Internal navigation directory displaying all 34 generated pages and routes.
/hero-tools 3D Tools Section Previews the 3D marketing badges scene in isolation.
/documentation/ Documentation Portal Serves this documentation site locally from the running Astro server.

Creating 2.5D Project Depth Maps (home_depth.webp)

Complete guide to how the two-image system works for portfolio projects, the WebGL parallax raymarching shader, and 4 practical methods to generate depth maps for new projects.

💡 The Two-Image System at a Glance
Every project in public/assets/projects/{slug}/ requires two synchronized images:
  • home.webp: The full-color hero artwork (1200 × 900 px).
  • home_depth.webp: The grayscale spatial depth map (1200 × 900 px).

1. Why Are There 2 Images for Each Project?

When browsing the portfolio gallery at /projects, each project card is not a flat 2D picture. Instead, it is rendered as a dynamic, interactive 2.5D spatial hologram using Three.js and a custom GLSL fragment shader (frag$l in src/scripts/runtime/navigation/pages/ProjectsPage.js).

As the user moves their mouse or scrolls, the camera angle shifts and the shader calculates real-time perspective distortion, depth of field (DoF blur), and optical parallax.

File Name Channel Data Role in WebGL Pipeline
home.webp RGB Color (24-bit) Provides the base photographic or 3D rendered surface visual (u_texture).
home_depth.webp Grayscale Luminance (8-bit) Provides the spatial depth coordinates (u_depthTexture) for raymarching parallax.

2. How the Raymarching Parallax Shader Works

Inside ProjectsPage.js, each project card instantiates a custom UfxMesh configured with: 

(this.ufxMesh.material.defines.PARALLAX_SAMPLES = 12),
(this.ufxMesh.material.defines.BLUR_SAMPLES = 6);

The fragment shader marches a ray through 12 virtual depth layers to locate the exact surface intersection:

src/scripts/runtime/navigation/pages/ProjectsPage.js (GLSL Shader excerpt) 
// 12-step raymarching depth loop
for (int i = 0; i < PARALLAX_SAMPLES; i++) {
  // Sample the red channel (.r) of home_depth.webp
  float currZ = -texture2D(u_depthTexture, rayPos.xy * toUvSpace + .5).r * zMultiplier;
  if (currZ > rayPos.z) {
    break; // Ray hit the geometry surface!
  }
  rayPos += rayStep;
  dist += stepDist;
}

// Compute depth-of-field blur based on focus distance
float depth = texture2D(u_depthTexture, uv + .5).r;
float blurriness = mix(0.0, 0.01, u_zoomRatio) * linearStep(0.0, 0.5, abs(depth - u_focusPos.z) + u_dofRangeOffset);
Luminance Rule: White vs Black
  • Pure White (#ffffff, value 1.0) = Foreground / Closest to screen. These elements shift the most with mouse movements and pop outward.
  • Pure Black (#000000, value 0.0) = Background / Deepest distance. Stays anchored far behind in the scene.
  • Intermediate Grays = Continuous linear transition from foreground to background.

3. Image Specifications & Requirements

For optimal visual clarity and zero artifacting in WebGL, adhere to these technical specs:

Property Specification Why It Matters
Dimensions 1200 × 900 px (4:3 ratio) Must match home.webp pixel-for-pixel so depth lines align with color contours.
File Format .webp Lossless or high-quality lossy (quality ≥ 85) for minimal file size and rapid network delivery.
Color Space Grayscale (sRGB) The shader samples the .r channel; single grayscale maintains 1:1 color mapping.
Target Path public/assets/projects/{slug}/home_depth.webp Loaded dynamically by ProjectsPage.js via settings.PROJECT_PATH + this.id + "/home_depth.webp".

4. Step-by-Step: 4 Ways to Create a New Depth Image

Method 1: Free Online AI Estimator (Recommended — 15 Seconds)

Modern AI depth models produce photorealistic depth maps from any 2D image without needing 3D models or manual painting:

  1. Open the free Depth Anything V2 Space on Hugging Face ↗.
  2. Upload your home.webp (or high-res JPG/PNG artwork).
  3. Select the model: Depth-Anything-V2-Large (best quality and sharpest silhouettes).
  4. Click Generate. Within 3–5 seconds, your grayscale depth map is ready.
  5. Download the output image (PNG or JPG).
  6. Convert and resize it to 1200x900 WebP using the terminal: 
    # Using cwebp (installed on your system):
cwebp -q 90 -resize 1200 900 depth_output.png -o public/assets/projects/your_project/home_depth.webp

# Or using ImageMagick:
magick depth_output.png -resize 1200x900^ -gravity center -extent 1200x900 -colorspace Gray public/assets/projects/your_project/home_depth.webp

Method 2: 3D Renders (Blender / Cinema 4D / Maya)

If your project artwork is created in a 3D application:

  1. In Blender:
    • Go to View Layer Properties → Enable Z or Mist pass.
    • In the Compositor, connect the Depth output to a Normalize node or Map Range node.
    • Invert if necessary so closest objects are white (1.0) and far background is black (0.0).
    • Render at 1200x900 and export as home_depth.webp.
  2. In Cinema 4D:
    • Open Render Settings → Multi-Pass → Add Depth pass.
    • Configure the Camera Focus Distance and Depth Target.
    • Export the pass as 16-bit or 8-bit grayscale.

Method 3: Adobe Photoshop / Photopea (Neural Filters or Painting)

  1. Using Neural Filters:
    • Open your project image in Photoshop.
    • Go to Filter → Neural Filters → Toggle on Depth Blur.
    • Check the box at the bottom: Output Depth Map Only.
    • Click OK, flatten the image, invert colors if background is white (Ctrl/Cmd + I), and save.
  2. Manual Painted Depth Mask:
    • Create a new layer above your image.
    • Fill the background with solid black (#000000).
    • Select your foreground subjects and paint them solid white (#ffffff).
    • Paint midground elements with intermediate grays (e.g., #808080).
    • Apply a slight Gaussian Blur (1–2px) to prevent jagged step-shearing in the raymarching shader.

Method 4: Automated Terminal / Python Script

If you want to automate depth map creation locally, you can use Python with the transformers library:

generate_depth.py 
# Install prerequisites once:
# pip install torch torchvision transformers pillow

import sys
from PIL import Image
import torch
from transformers import pipeline

if len(sys.argv) < 3:
    print("Usage: python generate_depth.py input_image.png output_depth.webp")
    sys.exit(1)

input_path, output_path = sys.argv[1], sys.argv[2]
pipe = pipeline(task="depth-estimation", model="depth-anything/Depth-Anything-V2-base-hf")
image = Image.open(input_path).convert("RGB")
depth = pipe(image)["depth"]

# Resize to standard KYNDEV 1200x900 dimensions
depth = depth.resize((1200, 900), Image.Resampling.LANCZOS)
depth.save(output_path, "WEBP", quality=90)
print(f"✓ Saved depth map to {output_path}")

6. Troubleshooting & Common Pitfalls

Symptom Root Cause Solution
Background moves forward, foreground moves backward Inverted depth map (white background, black foreground). Invert the image in Photoshop (Ctrl/Cmd + I) or ImageMagick (-negate). White must be nearest.
Jagged edges or pixel tearing on card tilt Hard, 1-pixel stair-stepped depth edges. Apply a gentle 1.0–2.0px Gaussian blur along high-contrast silhouettes.
Image looks stretched or misaligned Dimension mismatch between home.webp and home_depth.webp. Ensure both files are exactly 1200 × 900 px.

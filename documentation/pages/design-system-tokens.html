Design System & Token Specifications

The official design tokens, typography scales, 12-column grid geometry, and component templates extracted from the live KYNDEV front-end experience.

1. Color Palette Tokens

All core color tokens are defined in src/styles/kyndev.css:

Token Name Hex / RGBA Value Role & Usage
--color-blue #1a2ffb Primary electric brand accent; CTAs, links, and high-impact states.
--header-color #0016ec Top navigation buttons, active menu states.
--color-dark-blue #071bdf Deep blue accents and gradient end-stops.
--color-white #ffffff High-contrast typography and default light mode background.
--color-black #000000 Canvas base color, inverted page modes.
--color-off-white #f0f1fa Secondary background, subtle card fills.
--color-green #c1ff00 Neon volt accent; used in ScrollNav progress bar track.
--color-grey-blue #2b2e3a Muted neutral; pill backgrounds and secondary badges.

Dynamic Case Study Theme Tokens

Each project in src/data/projects.json injects custom ambient theme variables into src/pages/projects/[slug].astro:

  • --project-details-bg: Ambient page background color.
  • --project-details-highlight: Accent highlight color.
  • --project-details-btn-bg / --project-details-btn-text: Dynamic button colors.

2. Typography & Fluid Font Scale

KYNDEV uses a strict font hierarchy with fluid responsive sizing:

Font Family Weights Usage
Aeonik Regular (400), Medium (500), Italic Primary display titles, hero typography, body text, and headlines.
IBM Plex Mono Regular (400), Medium (500) Numerical telemetry, dates, coordinates, and technical metadata.
LusionMono Regular (400) Ticker text and secondary readouts.

Fluid Responsive Type Rules

.text-xs   { font-size: 0.75em; }
.text-base { font-size: clamp(1rem, 1.5vw, 2rem); }
.text-lg   { font-size: 1.75em; }
.text-4xl  { font-size: clamp(7em, 8vw, 20em); }

3. 12-Column Spatial Grid

Every page section implements the responsive .section grid:

src/styles/kyndev.css 
:root {
  --grid-gap: 2vw;
  --grid-space: calc((100% - 11 * var(--grid-gap)) / 12);
  --base-padding-x: max(5vw, 40px);
  --base-padding-y: clamp(30px, 4vw, 50px);
  --global-border-radius: 20px;
}

.section {
  position: relative;
  width: 100%;
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  column-gap: var(--grid-gap);
  padding: var(--base-padding-y) var(--base-padding-x);
}

@media (max-width: 812px) {
  .section {
    grid-template-columns: repeat(6, minmax(0, 1fr));
    --base-padding-x: 25px;
    --base-padding-y: 25px;
  }
}

4. Alignment Cross Pins (.cross)

A signature visual motif of the studio is the absolute cross-pin alignment markers positioned on container corners: 

.cross {
  position: absolute;
  width: var(--cross-size);
  height: var(--cross-size);
}
.cross:before, .cross:after {
  content: "";
  position: absolute;
  background: currentColor;
}
.cross:before {
  top: 50%; left: 0; width: 100%; height: 1px;
}
.cross:after {
  left: 50%; top: 0; height: 100%; width: 1px;
}

5. Component Creation Blueprint

When developing a new section component for any page, follow this verified template:

src/components/example/ExampleSection.astro 
---
interface Props {
  headline?: string;
  tagline?: string;
}

const { headline = "Precision Engineering", tagline = "01 / CAPABILITIES" } = Astro.props;
---

<section id="example-section" class="section">
  <!-- Cross alignment markers -->
  <div class="cross top-left"></div>
  <div class="cross top-right"></div>

  <!-- Content spanning 12-column grid -->
  <div style="grid-column: span 5;">
    <span class="text-xs">{tagline}</span>
    <h2 class="text-lg">{headline}</h2>
  </div>

  <div style="grid-column: span 7;">
    <p class="text-base">
      Integrating high-performance WebGL graphics with seamless editorial narrative.
    </p>
  </div>
</section>
